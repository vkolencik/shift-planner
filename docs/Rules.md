# Rules for possible solutions

1. Basic constraints
   1. Every shift has exactly one employee
   2. No employee has more than 1 shift in a given day
2. No consecutive shifts
3. At most *n* shifts in a month with only 1 day in between?
4. Employee qualification distribution:
   1. At least 1 employee with qualification at least *x*?
   2. Something else?
   3. Does qualification depend on workplace? 
5. Min/max shifts per worker/month 
6. Max *n* shifts in weekends (and holidays?)
7. days off (days without shifts for a given employee)
8. employee/shift type compatibility (employee x cannot work in shift y)
   1. soft version of above - shift type preferences
