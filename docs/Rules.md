# Rules for possible solutions

1. Basic constraints
   1. Every shift has exactly one employee
   2. No employee has more than 1 shift in a given day
2. No consecutive shifts
3. At most *n* shifts in a month with only 1 day in between for a given employee
4. Employee qualification distribution:
   1. At least 1 employee with qualification at least *x*?
5. Min/max shifts per worker/month 
6. Max *n* shifts in weekends (and holidays?)
7. Shift preferences (days without shifts for a given employee)
   1. Hard no (days off)
   2. Soft no
   3. Soft yes (preference)
8. Employee/shift type compatibility
   1. Hard no (employee x unqualified for y)
   2. soft yes (workplace preference)
